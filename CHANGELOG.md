# Changelog

## 0.1.0

- Initial public-alpha release for GitHub clone-first usage.
- Local `llmw` CLI for source registration, ingest packets, search, query,
  health checks, maintenance, release checks, and audited package builds.
- MCP server exposing context, search, query, maintenance, benchmark, plan, and
  safe apply tools for agent runtimes.
- Codex integration helpers and local plugin template.
- Source registry, maintained Markdown wiki pages, Obsidian-style links,
  index/log maintenance, and source-backed health checks.
- Fast local search with Python rank index caching, optional qmd deep search,
  search daemon support, and built-in benchmark gates.
- Public example wiki about agent development, plus docs for quickstart, MCP,
  demo, publishing, security, and the Karpathy LLM Wiki pattern.
