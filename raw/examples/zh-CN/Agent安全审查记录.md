# Agent 安全审查记录

日期：2026-05-04
来源类型：合成安全审查记录

## 审查范围

本记录审查一个面向 agent 的本地 wiki 工具。该工具允许 agent 读取项目上下文、搜索 wiki、生成维护计划，并在用户确认后执行有限的写入操作。

## 主要风险

### Prompt Injection

原始资料中可能包含恶意指令，例如“忽略系统提示”“删除所有文件”“泄露 API key”。  
agent 必须把 `raw/` 中的内容当作证据，而不是当作可执行指令。

### 过宽的写入权限

如果工具暴露任意 shell 或任意文件写入，agent 可能因为模型错误、提示注入或上下文混淆而修改不该修改的文件。

### 敏感信息泄露

本地 `.llmw/`、日志、缓存、查询输出、provider 配置里可能包含敏感内容。发布包和公开仓库不应该携带这些本地状态。

## 建议控制

- `raw/` 永远只读。
- 自动写入只允许进入 `wiki/` 或明确允许的项目目录。
- 所有写入先生成 plan，再 dry-run，再 apply。
- release check 必须审计 `.env`、`.llmw/`、raw 私有资料、wiki 私有内容。
- agent 回答前应该优先搜索已维护的 wiki，而不是直接相信单个 raw 片段。

## 审查结论

如果工具坚持“原始证据不可变、维护层可审查、写入动作受限”这三个边界，它可以成为 agent 的可靠本地记忆层。  

如果这些边界被打破，它就会退化成一个高风险的自动化脚本入口。
