# AutoGen Agent and Multi-Agent Applications

This source card points to Microsoft AutoGen documentation on agents and multi-agent applications.

## Why This Matters

AutoGen is useful as a contrasting framework for multi-agent application design. It emphasizes message-driven agent interactions and composable roles.

## Key Ideas To Extract

- Agent as an entity that sends and receives messages.
- Multi-agent applications as coordinated conversations or workflows.
- Role separation across specialized agents.
- Runtime and orchestration concerns in agent systems.
