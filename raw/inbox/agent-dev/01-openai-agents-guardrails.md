# OpenAI Agents SDK Guardrails

This source card points to the OpenAI Agents SDK guardrails documentation. It is useful for building a wiki section on agent safety boundaries, validation stages, and failure handling.

## Why This Matters

Guardrails are a practical mechanism for constraining agent behavior before or after model execution. In agent systems, guardrails can protect workflows from unsafe inputs, malformed outputs, policy violations, or tool misuse.
