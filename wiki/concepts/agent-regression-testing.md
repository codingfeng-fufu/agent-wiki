# Agent Regression Testing

Agent regression testing reruns representative tasks to detect behavior changes. The tracing source card connects traces to evaluation and regression testing.

## Test Inputs

- Prior [[Agent Tracing]] records.
- Expected guardrail outcomes.
- Expected page, log, or index changes in file-driven workflows.
