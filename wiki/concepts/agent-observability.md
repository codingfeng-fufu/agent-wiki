# Agent Observability

Agent observability is the ability to inspect, debug, and evaluate agent behavior beyond the final answer. The tracing source card frames traces as a structured record of agent behavior.

- [[Agent Tracing]] spans for workflow steps.
- [[Tool Call Logs]] for action-level visibility.
